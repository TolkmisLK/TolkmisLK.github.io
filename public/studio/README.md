# 工作室插画

这三张图片是网站装饰插画，不是项目运行截图。通过内置 ImageGen 生成后，使用 Sharp 等比例缩小并转为 WebP；猫的透明通道保留。

- `workspace.webp`：1200 × 800，书桌场景。
- `cat.webp`：320 × 320，清醒的小猫。
- `cat-sleep.webp`：320 × 320，同一小猫的睡姿。

## 生成提示词摘要

1. **书桌**：3:2 横向编辑插画，奶油纸色、鼠尾草绿、蜂蜜橡木和少量陶土色，细腻水粉质感。桌面约在画面下方四分之一，左侧可点击的绿色台灯，中央偏左显示 NCC 的电脑，咖啡杯和右侧植物；右侧桌面留空，后续叠加猫。不要网页界面或产品截图。
2. **清醒猫**：独立透明背景的橘白猫，坐姿，尾巴卷向右侧，温柔圆眼，水粉插画风格，暖赭石毛色、米白胸口和爪子；完整轮廓，适合缩小显示，画面外不加地板或阴影。
3. **睡姿猫**：以清醒猫为编辑参考，保留角色、毛色、笔触和透明背景。闭眼、身体趴成一团、头稍低；与原图保持相同的脚底基线和大致比例，上方留透明空间，切换姿势时不改变画布尺寸。

热点位置由 `app/studio-scene.css` 控制。更换插画后请同时检查台灯点击区、两种猫姿势的脚底位置，以及手机布局。图片路径沿用站点配置中的部署子路径。
